## 强制执行契约 · 落盘与记忆写入（最高优先级）

> 本卡片是「禁止工具幻觉 / 虚假完成声明」的硬约束，覆盖 `AGENTS.md` 第 1 条写入规则。

### 铁律：禁止无工具调用的"完成声明"

任何写入文件、新增记录、修改文档类动作，**只有成功调用 `edit_file` / `write_file` 工具才算执行完成**。不允许口头说"已经写入 XX.md"，没有工具调用 = 操作未发生。

### 流水线（顺序不可调换、不可省略任何一步）

1. **判定目标文件**：严格按 AGENTS.md 文件地图分类
   - 工具/接口异常 → `bugs.md`
   - 成功做法或踩坑 → `lessons.md`
   - 用户语言/风格/兴趣 → `preferences.md`
   - 当前图谱的领域知识 → `knowledge_base.md`
   - 可复用的工作流模板 → `patterns.md`
   - **禁止放错文档**（如 bug 写进 AGENTS.md）

2. **调用文件编辑工具写入内容**：`edit_file` 或 `write_file`

3. **校验**：调用 `read_file` 或 `grep` 读取目标位置，确认条目真实存在

4. **向用户汇报**：汇报必须附带【文件路径 + 行数 + 校验结果】作为凭证

### 汇报模板（强制套用，禁止自由发挥）

```
✅ 操作完成凭证
文件路径：/xxx/bugs.md
操作类型：新增 BUG 条目
校验方式：grep 检索 BUG 编号
校验结果：存在，位于第 XX 行
```

### 禁止行为清单

- ✖ 不允许先向用户汇报"已记录"再补操作
- ✖ 不允许省略校验步骤
- ✖ 不允许自行修改文件归属
- ✖ 不允许编造"写入成功"的位置信息

### 违规处理

一旦发生"口头宣称已写入，但未调用工具"：
1. 立刻识别违规
2. 停止所有其他任务
3. 优先补执行完整流水线
4. 主动复盘违规原因，等待用户确认后继续会话

### 反面案例（本次 BUG-004 事故）

❌ **错误示范**：口头承诺写入 AGENTS.md，未调用编辑工具，后续分类判断出错（应是 bugs.md 而非 AGENTS.md），无校验，被用户当场识破。
✅ **正确示范**：选定 `bugs.md` → 调用 `edit_file` 写入 → `grep` 校验条目存在 → 附带文件位置凭证汇报。
