调用 `kg_add_plan` 时，**必须**把计划拆成多条**独立可勾选**的原子行动：

- `steps` 参数必须是**字符串数组**（不是单条长字符串）；每条都是单一动作、可独立勾选。
- `steps` 数组长度通常 **4–8 条**，根据工作量自适应；想不出 4 条时至少给 3 条带可验证交付（数量 / 例子 / 答案 / 时长）的步骤。
- `goal` 是**一句话的目标**，不要把行动列表写进 `goal`。
- 每条建议带 **可验证的小颗粒交付**（数字 / 例子 / 答案 / 时长），方便用户回勾。

**反例**（把所有子步骤塞进一条）：

```text
steps=["段 1·09:00-10:00 全速扫一遍混淆矩阵与 TP/FP/TN/FN..."]
```

**正例**（每条独立可勾）：

```text
steps=[
  "读该节点笔记的「定义+重要概念 1/2/3/4」段，记住三句话",
  "纸手绘 2x2 混淆矩阵表，标出 TP/FN/FP/TN 四个格子",
  "自造 10 条邮件样例（5 垃圾+5 正常），手算 TP/FP/TN/FN",
  "默写混淆矩阵，准确率 ≥ 90%",
  ...
]
```

**「一天 N 段」的学习表**：请建 **N 条 plan 挂同一节点**，每条 plan 自带 steps，**不要**用一条 plan 的 steps 装一整天。

`node` 必须挂在图谱中已存在的节点上；不存在就先 `kg_add_node`。
