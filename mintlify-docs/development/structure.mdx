## 关键不变量

1. `domain/` 不导入 `infrastructure` / `application` / `api` / `agent`
2. `api/routes/` 零直接文件 IO（必须走 Repository）
3. 工具数 = 53（由 `test_tool_count_consistency` 守护）
4. 所有 LLM 客户端实现 `LLMClientProtocol`（结构化子类型）
5. 写操作必 emit ActivityBus 事件
