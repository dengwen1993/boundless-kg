## 速查

完整分组见下表。所有变量在 `src/config/settings.py` 定义，模板见项目根目录的 `.env.example`。

## LLM

| 变量 | 默认 | 说明 |
| --- | --- | --- |
| `KG_LLM_PROVIDER` | `mock` | Agent 聊天：`mock` / `minimax` / `deepseek` / `openai` |
| `KG_GENERATION_LLM_PROVIDER` | （空 → 回退） | 图谱生成 / 笔记 / 资源分类 |
| `KG_NOTE_LLM_PROVIDER` | （空 → 回退） | 仅笔记生成 |
| `KG_LLM_TIMEOUT_SEC` | `300` | 单次 LLM HTTP 超时（秒） |
| `KG_LLM_REASONING_EFFORT` | （空） | `low` / `medium` / `high` / `max` / `xhigh` |

## 路径

| 变量 | 默认 | 说明 |
| --- | --- | --- |
| `KG_KB_ROOT` | `./workspace/knowledge_bases` | 知识库根 |
| `KG_WORKSPACE_DIR` | `./workspace` | 工作区根 |

**跨平台写法**：

| 写法 | 例子 | 解析 |
| --- | --- | --- |
| POSIX 绝对 | `/app/workspace` | 原样使用 |
| Windows 绝对 | `C:\workspace` | 原样使用 |
| 相对 | `./workspace` | 解析为 `<CWD>/workspace` |

## 密钥缺失行为

任何缺失的**必填**密钥都会以 `EnvironmentError` 抛出，**绝不**回退到源码硬编码。

`config.require_secret(value, var_name)` 是统一入口。
