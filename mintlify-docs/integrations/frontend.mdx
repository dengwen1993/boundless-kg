## 单页 + 三视图（无 vue-router）

`frontend-vue/src/main.ts` —— **没有 vue-router**，整个应用是一个 SPA，通过 Pinia store 切换视图：

```typescript
// stores/graph.ts
type ViewMode = 'graph' | 'outline' | 'associations'
export const useGraphStore = defineStore('graph', () => {
  const viewMode = ref<ViewMode>('graph')
  return { viewMode, ... }
})
```

```vue
<!-- App.vue -->
&lt;template&gt;
  <TopBar />
  <div class="workspace">
    <GraphCanvas v-if="graphStore.viewMode === 'graph'" />
    <OutlineView v-else-if="graphStore.viewMode === 'outline'" />
    <AssociationsView v-else />
    <NodeNotePanel />
    <ChatPanel />
  </div>
</template>
```

**为什么不上 vue-router？** 单页应用，URL 不需要承载视图状态（视图状态在 store）。简化心智负担，build 也更快。

## 三视图对比

| 视图 | 适合 | 渲染 |
| --- | --- | --- |
| **Graph** | 整体结构概览 | D3 力导向图 |
| **Outline** | 学习路径、纵向展开 | Mermaid 大纲 / 思维导图 |
| **Associations** | 关联图（语义关系） | D3 力导向 + 边标注关系类型 |

切换不重新请求数据——所有视图共享 `graphStore` 里的图谱数据。

`frontend-vue/src/components/GraphCanvas.vue`：

- D3 力导向 + 树形布局切换

## API 客户端

`frontend-vue/src/api/index.ts`：

```typescript
const api = axios.create({ baseURL: '/api' })

export const graphApi = {
  listDomains: () => api.get('/domains').then(r => r.data),
  getGraph: (domain: string) => api.get(`/graph/${domain}`).then(r => r.data),
  addNode: (payload: AddNodeRequest) => api.post('/nodes', payload).then(r => r.data),
  patchNode: (domain: string, name: string, patch: NodePatch) =>
    api.patch(`/nodes/${domain}`, { ...patch, name }).then(r => r.data),
  deleteNode: (domain: string, name: string) =>
    api.delete(`/nodes/${domain}`, { params: { name } }).then(r => r.data),
}
```

SSE 走原生 `fetch`（见 [SSE 流式对话](/guides/sse-chat)）。

## 开发

```bash
cd frontend-vue
npm install
npm run dev          # → http://localhost:5175
npm run build        # → dist/ （Docker 镜像会拷进 /app/static）
npm run lint
npm run type-check
```

Vite dev server 自动代理 `/api` → `http://localhost:8888`。

## 构建产物进 Docker

```bash
cd frontend-vue && npm run build
# 产物：frontend-vue/dist/
# Dockerfile 多阶段构建会拷进 /app/static
# FastAPI server.py 用 StaticFiles 挂载
```
