## 它是什么

BoundlessKG 是一个**生产级知识图谱策展引擎**——围绕一个领域主题，自动构建并持续维护一棵可演化的知识图谱。

它不是单一行业的 demo，也不是单纯的 LLM 包装。它面向需要把**离散资料沉淀为可推理结构**的场景：学术综述、产品调研、技术决策树、跨领域学习路径……都能基于同一套引擎跑通。

## 为什么选 BoundlessKG

<AccordionGroup>
  <Accordion title="LLM 无关，按角色分配模型" icon="layer-group">
    Agent 聊天、图谱生成、笔记生成可以使用**三个不同的 LLM**。同一份 `.env` 既可以"MiniMax 聊 + DeepSeek 跑图谱"，也可以"agent 用 Claude + 生成用 GPT"。
    [查看 LLM 集成 →](/integrations/llm-providers)
  </Accordion>
  <Accordion title="图存储 + 文件树双源真相" icon="database">
    FalkorDB 持关联图与嵌入向量；文件系统持人类可读的领域数据。两者通过 `GraphSyncOrchestrator` 双向同步。任何一侧出问题时都能优雅降级。
    [查看 FalkorDB 集成 →](/integrations/falkordb)
  </Accordion>
  <Accordion title="全链路可观测" icon="chart-line">
    所有写操作通过 `ActivityBus` 自动发射事件，时间线、JSONL 日志、SSE 流都是同一份真相。不依赖反推文件系统重建历史。
    [查看事件总线 →](/concepts/event-bus)
  </Accordion>
  <Accordion title="生产级分层架构" icon="sitemap">
    `domain` 零 IO，靠 Protocol 反转依赖 `infrastructure`。新增 LLM / 搜索后端不需要改一行业务代码。
    [查看架构 →](/concepts/architecture)
  </Accordion>
</AccordionGroup>

## 5 分钟跑通

<Steps>
  <Step title="安装">
    ```bash
    git clone https://github.com/q85064972/boundless-kg.git boundless_kg && cd boundless_kg
    python -m pip install -e ".[dev,deepagents]"
    cp .env.example .env  # 填入至少一个 LLM 密钥
    ```

    > 📝 Apache License 2.0 — 自由使用、修改、分发，含专利授权。详见 [LICENSE](https://github.com/q85064972/boundless-kg/blob/main/LICENSE)。
  </Step>
  <Step title="启动后端">
    ```bash
    kg-engine serve
    # → http://localhost:8888
    ```
  </Step>
  <Step title="启动前端（可选）">
    ```bash
    cd frontend-vue && npm install && npm run dev
    # → http://localhost:5175
    ```
  </Step>
  <Step title="生成你的第一个领域">
    ```bash
    kg-engine generate "RAG 检索增强生成" --wait
    ```
    或者直接在前端聊天框里说："帮我创建一个名为 RAG 的领域图谱"。
  </Step>
</Steps>
